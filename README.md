# Trading Operating System (TOS) Professional Edition

## Overview

Trading Operating System (TOS) Professional Edition is a desktop application designed to become the central operating system for a discretionary trader.

Rather than being only a trading journal, TOS combines planning, execution, journaling, analytics, risk management and AI-assisted review into a single workflow.
